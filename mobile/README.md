# mobile — Nitro Modules & Fabric Native Components

This is the React Native project for the **Nitro Modules homework**. It uses React Native **0.79.1** with **Nitro Modules** (for native logic) and **Fabric** (for native views).

For the homework instructions, see the [root README](../README.md).

## Project structure

```
mobile/
├── packages/
│   └── nitro-notification/             # Local Nitro Module library
│       ├── nitro.json                   # Nitrogen configuration
│       ├── NitroNotification.podspec    # iOS CocoaPod spec
│       ├── src/
│       │   ├── Notification.nitro.ts    # HybridObject TypeScript spec
│       │   └── index.ts                 # JS entry point
│       ├── ios/
│       │   └── HybridNotification.swift # iOS implementation (Swift)
│       ├── android/
│       │   ├── build.gradle
│       │   ├── CMakeLists.txt
│       │   └── src/main/java/com/margelo/nitro/notification/
│       │       ├── NitroNotificationPackage.kt
│       │       └── HybridNotification.kt  # Android implementation (Kotlin)
│       └── nitrogen/generated/          # Generated by Nitrogen
├── specs/                               # Fabric Component specs (Codegen)
│   └── CustomButtonNativeComponent.ts
├── ios/mobile/
│   └── CustomButton/                    # iOS Fabric Component (Obj-C++)
│       ├── RCTCustomButton.h
│       └── RCTCustomButton.mm
├── android/app/src/main/java/com/mobile/
│   ├── MainApplication.kt              # Package registration + Nitro init
│   └── specs/                           # Android Fabric Component (Kotlin)
│       ├── CustomButtonView.kt
│       ├── CustomButtonViewManager.kt
│       └── CustomButtonPackage.kt
└── src/                                 # React Native app source
```

## Getting Started

### Prerequisites

Make sure you have completed the [Set Up Your Environment](https://reactnative.dev/docs/set-up-your-environment) guide.

### Install dependencies

```sh
npm install
```

### Generate Nitrogen specs (if modifying the Nitro library)

```sh
cd packages/nitro-notification
npx nitrogen
cd ../..
```

### iOS

```sh
bundle install
cd ios && bundle exec pod install && cd ..
npm run ios
```

### Android

```sh
npm run android
```

### iOS — Adding native files to Xcode

The CustomButton Fabric files (`.h` and `.mm`) in `ios/mobile/CustomButton/` need to be added to the Xcode project:

1. Open `ios/mobile.xcworkspace` in Xcode
2. Right-click the `mobile` group → **Add Files to "mobile"...**
3. Select the `CustomButton` folder
4. Make sure **"Create groups"** is selected and the `mobile` target is checked
5. Build the project

The Nitro notification library (`packages/nitro-notification/`) is linked automatically via CocoaPods.
